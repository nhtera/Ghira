# Keyboard shortcuts

These are the shortcuts in Ghira on a Mac. **Settings → Shortcuts** lists the
main ones.

## From any app

Two shortcuts work while another app is in front. This lets you start a
recording or mark a moment during a call without switching windows.

| Keys | What it does |
|---|---|
| ⌘⇧R | Start or stop recording. A call recording starts without taking focus, and the mini recorder shows what is happening. |
| ⌘M | Mark moment. Works only while a recording runs. |

They work after you finish the first-launch setup. You can turn each one off in
**Settings → Shortcuts → From any app**, for example if it clashes with another
tool. ⌘⇧R is also a common browser shortcut for a hard reload, which is why it
is a setting.

## Inside Ghira

| Keys | What it does |
|---|---|
| ⌘⇧R | Start or stop recording. |
| ⌘M | Mark moment while recording. |
| ⌘K | Open the command palette (**Search or Jump To…**). Type a command or search your meetings. |
| ⌘, | Open Settings. |
| ⌘F | Search your meetings in the library. In a transcript, find text in that meeting. |
| ⌘A | In the library, select every meeting shown. Esc clears the selection. |
| Space | Play or pause the meeting's audio. It works when you are not typing. |
| Enter | In **Your notes** while recording, add the note you typed. |
| ⌥1, ⌥2, ⌥3 | In **Your notes**, tag the next note as a decision, an action or a question. |

## App menu

| Keys | What it does |
|---|---|
| ⌘Q | Quit Ghira. If a recording is running, Ghira asks first. |
| ⌥⌘M | Minimize the window. (⌘M is Mark moment.) |

The **Lock Ghira** item in the Ghira menu locks the app. It has no shortcut, and
it works only when the app lock is on (**Settings → Privacy**).

## Limits

- The shortcuts are fixed. You cannot change the keys.
- Ghira also shows ⌘1, ⌘2 and ⌘E for the Notes tab, the Transcript tab and
  Export in some places, but they are not wired up yet. Use the buttons.
